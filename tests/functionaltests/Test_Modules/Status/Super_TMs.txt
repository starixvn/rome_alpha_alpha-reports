    ...

    ...    5. Confirm Cancel

    ...    7. Re-Closed and Confirm OK
    ...    8. VP: Master is closed
    ...    9. Drill down to agent list by click on view link

    ...    11. Drill down to member list by click on view link

    ...    13. Login with master account
    ...    14. VP: Can not login
    ...
    ...    *Expected:*
    ...
    ...    4.VP: Pop-up appears 'Are you sure you want to change Close status for this customer? Warning, all downlines will be closed as well!

    ...    10.VP: All Agents of that Master are closed
    ...    12.VP: All members of that agent are closed
    ...    14.VP: warning 'Account closed. Please contact your administrator!'
    [Tags]    super_status
    COMMENT    ==============================>    PRE-CONDITION
    ${tm_master}    Set Variable    SUPERTESTAUTO101
    Open Page
    Login    ${cf_super_auto}    ${cf_acc_pass}    ${EMPTY}
    COMMENT    ==============================>    MAIN STEPS

    edit checkbox setting    Closed    check
    # wait for updating process
    sleep    5s
    #drill down Agent
    Open Downlines List
    check all customer table cell    tblCustomerList    3    Close
    #drill down member
