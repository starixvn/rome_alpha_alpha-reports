*** Keywords ***
Change Password
    [Arguments]    ${action}    ${oldPassword}='${EMPTY}'    ${newPassword}='${EMPTY}'
    Run Keyword If    '${oldPassword}'!='${EMPTY}'    Input Text    ${in_m_cpw_txtOldPassword}    ${oldPassword}
    Run Keyword If    '${oldPassword}'!='${EMPTY}'    Input Text    ${in_m_cpw_txtNewPassword}    ${newPassword}
    Run Keyword If    '${oldPassword}'!='${EMPTY}'    Input Text    ${in_m_cpw_txtConfirmPassword}    ${newPassword}
    Run Keyword If    '${action}'!='save'    Click Element    ${in_m_cpw_btnSubmit}
    Run Keyword If    '${action}'!='reset'    Click Element    ${in_m_cpw_btnReset}

Reset password
    [Arguments]    ${ac_username}    ${ac_newpwd}    ${ac_isUpdated}==1
    [Documentation]    This action is used to reset downline password
    ...    ${ac_newpwd}: the new value of password
    ...    ${ac_isUpdated}: click update button or not
    Unselect Frame
    Select Frame    main
    ##
    ${ac_Title}    Evaluate    "Reset Password - ${ac_username}".upper()
    Wait Until Element Contains    ${in_m_Pwd_tdTitle}    ${ac_Title}
    ##
    Input Password    ${in_m_Pwd_txtPwd}    ${ac_newpwd}
    Input Password    ${in_m_Pwd_txtPwdConfirm}    ${ac_newpwd}
    ##
    Run Keyword If    '${ac_isUpdated}'=='1'    Click Element    ${in_m_Pwd_btnSubmit}
