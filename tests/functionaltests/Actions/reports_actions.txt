    ...    ${ac_row}: the row that contains data need to check
    ...
    ...    ${ac_col_TotalWinloss}: the column index of Super/Master/Agent/Member Total Winloss
    ...
    ...    ${ac_Level_Report}: Master/Agent/Member
    ...
    ...    ${ac_boundary_number}: the bound of error
    ## Set variable
